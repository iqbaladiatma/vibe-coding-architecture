## 🧠 What is "Vibe Coding"?
Vibe Coding is a paradigm shift where the developer acts as an **Architect/Orchestrator** rather than a manual syntax writer. By utilizing Large Language Models (LLMs) and Model Context Protocol (MCP), developers can generate massive amounts of functional code. 

However, it heavily relies on **Human-in-the-Loop Validation**—the developer must manually review, debug, and enforce architectural integrity and security standards.

## ⏱️ The 7-Day Sprint Case Study
Using this methodology, a comprehensive, ISO 9001:2015 compliant Management Information System for an educational institution was built in just **7 days** as a solo developer:
* **Day 1:** Schema & Architectural Design (2 hours).
* **Day 2-5:** AI-Assisted Code Generation (CRUD, APIs, Business Logic).
* **Day 6-7:** Human-in-the-Loop Debugging, Security Patching, & Deployment.
* **Result:** 70–85% AI-generated codebase, 15–30% manually refined.
